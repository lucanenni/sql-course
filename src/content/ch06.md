## Raggruppare

`GROUP BY colonna` divide le righe in **gruppi** con lo stesso valore di quella colonna. L'aggregato viene poi calcolato **dentro ogni gruppo**, e il risultato ha una riga per gruppo.

```sql
SELECT categoria, count(*) AS n
FROM   prodotti
GROUP BY categoria;
```

Risultato: una riga per categoria, con quanti prodotti contiene.

La regola: nel `SELECT` puoi mettere **le colonne del `GROUP BY`** e **funzioni di aggregazione**, nient'altro.

## Filtrare i gruppi: HAVING

`WHERE` filtra le righe **prima** del raggruppamento. Per filtrare **dopo**, sui valori aggregati, si usa `HAVING`:

```sql
SELECT categoria, count(*) AS n
FROM   prodotti
GROUP BY categoria
HAVING count(*) >= 3;      -- solo le categorie con almeno 3 prodotti
```

::: analogy WHERE vs HAVING
`WHERE` sceglie chi entra in sala; `GROUP BY` divide i presenti in tavoli; `HAVING` decide quali tavoli tenere in base a quanti sono seduti.
:::

::: exercise c6-having

## L'ordine completo

```sql
SELECT   ...
FROM     ...
WHERE    ...        -- filtra le righe
GROUP BY ...        -- forma i gruppi
HAVING   ...        -- filtra i gruppi
ORDER BY ...        -- ordina il risultato
LIMIT    ...;
```
