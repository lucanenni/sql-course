## La query minima

Ogni interrogazione parte da due parole:

```sql
SELECT <colonne>
FROM   <tabella>;
```

`FROM` dice **da quale tabella** leggere, `SELECT` dice **quali colonne** vuoi indietro. Il `;` finale chiude l'istruzione.

## Tutte le colonne: `*`

L'asterisco `*` è una scorciatoia per «tutte le colonne, nell'ordine in cui sono definite».

```sql
SELECT * FROM clienti;
```

Comodo per dare un'occhiata a una tabella che non conosci. Nelle query "vere" conviene però elencare solo le colonne che servono.

## Scegliere le colonne

Elenca i nomi delle colonne separati da virgola. L'ordine in cui li scrivi è l'ordine in cui compaiono nel risultato.

```sql
SELECT citta, nome FROM clienti;
```

::: tip L'ordine delle righe
Senza un `ORDER BY` (capitolo 3) il database può restituire le righe in **qualsiasi ordine**. Per gli esercizi non è un problema: il controllo ignora l'ordine, a meno che l'esercizio non chieda esplicitamente di ordinare.
:::
