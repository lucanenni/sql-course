## Fin qui abbiamo solo letto

`SELECT` non tocca niente. Le tre istruzioni di questo capitolo invece **cambiano** il contenuto delle tabelle. Nel corso ogni esercizio parte da un database pulito, quindi puoi sperimentare senza paura: dopo la verifica trovi la tabella nello stato risultante.

## INSERT — aggiungere righe

```sql
INSERT INTO clienti (nome, citta, eta, iscritto_il)
VALUES ('Nuova Cliente', 'Milano', 33, '2024-02-01');
```

Elenchi le colonne che valorizzi, poi i valori **nello stesso ordine**. Le colonne non citate prendono il loro valore di default (o `NULL`).

::: exercise c9-insert

## UPDATE — modificare righe esistenti

```sql
UPDATE prodotti
SET    prezzo = prezzo * 1.1
WHERE  categoria = 'Elettronica';
```

`SET` assegna i nuovi valori (può usare quelli attuali). Il `WHERE` sceglie **quali** righe: senza `WHERE`, `UPDATE` cambia **tutte** le righe della tabella.

::: warning Il WHERE dimenticato
`DELETE FROM ordini;` cancella *tutti* gli ordini. `UPDATE prodotti SET prezzo = 0;` azzera *tutti* i prezzi. Prima di lanciare un `UPDATE`/`DELETE`, prova lo stesso `WHERE` con una `SELECT` e controlla quante righe colpisce.
:::

::: exercise c9-update

## DELETE — eliminare righe

```sql
DELETE FROM ordini
WHERE  stato = 'annullato';
```

Stesso `WHERE` di una `SELECT`. Elimina intere righe: non esiste "cancellare una singola colonna" con `DELETE` (per quello si usa `UPDATE ... SET colonna = NULL`).

::: exercise c9-delete

::: tip Creare tabelle
Le tabelle si creano con `CREATE TABLE nome (colonna TIPO, ...)` e si eliminano con `DROP TABLE nome`. I tipi principali in SQLite sono `INTEGER`, `REAL`, `TEXT`. Nel corso lo schema è già pronto, ma è utile saperlo leggere: apri il pannello **Schema** sotto un esercizio.
:::
