## Da tante righe a un valore

Le **funzioni di aggregazione** guardano un'intera colonna e restituiscono **una riga sola**:

| Funzione | Cosa fa |
|---|---|
| `count(*)` | quante righe |
| `count(colonna)` | quante righe con quella colonna non-`NULL` |
| `sum(colonna)` | somma dei valori |
| `avg(colonna)` | media |
| `min(colonna)` / `max(colonna)` | minimo / massimo |

```sql
SELECT count(*) FROM ordini;          -- quanti ordini
SELECT avg(prezzo) FROM prodotti;     -- prezzo medio
```

Ricorda l'alias, altrimenti la colonna si chiama `count(*)`:

```sql
SELECT count(*) AS numero_ordini FROM ordini;
```

## count e DISTINCT

`count(DISTINCT colonna)` conta i **valori diversi**, non le righe:

```sql
SELECT count(DISTINCT citta) AS citta_servite
FROM   clienti;
```

::: exercise c5-distinct

## Aggregati e WHERE

Il `WHERE` filtra **prima** dell'aggregazione: così l'aggregato lavora solo sulle righe rimaste.

```sql
SELECT avg(prezzo) AS media_elettronica
FROM   prodotti
WHERE  categoria = 'Elettronica';
```

::: warning Non mischiare aggregati e colonne normali
`SELECT nome, count(*) FROM prodotti;` non ha senso: `count(*)` è un numero solo, `nome` sono dieci valori. Per avere "un conteggio **per** ogni nome/categoria" serve `GROUP BY` — il prossimo capitolo.
:::
