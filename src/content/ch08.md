## Una query come valore

Una **sottoquery** è una `SELECT` fra parentesi usata dentro un'altra query. Se restituisce **un solo valore**, la usi come se fosse un numero:

```sql
SELECT nome, prezzo
FROM   prodotti
WHERE  prezzo > (SELECT avg(prezzo) FROM prodotti);
```

Prima il database calcola `avg(prezzo)` (un numero), poi lo usa nel confronto. Comodo quando il valore di paragone dipende dai dati stessi.

::: exercise c8-scalar

## Una query come elenco: IN

Se la sottoquery restituisce **una colonna con più valori**, la usi con `IN` / `NOT IN`:

```sql
SELECT nome
FROM   clienti
WHERE  id IN (SELECT cliente_id FROM ordini WHERE stato = 'annullato');
```

La sottoquery produce l'elenco dei `cliente_id` con un ordine annullato; `IN` tiene i clienti che vi compaiono.

::: exercise c8-in

::: exercise c8-notin

## Una query come tabella: sottoquery nel FROM

Puoi mettere una sottoquery al posto di una tabella nel `FROM`: diventa una **tabella temporanea** su cui lavorare. Utile per filtrare un risultato aggregato (dove `HAVING` non basta o non è comodo).

```sql
SELECT categoria, media
FROM (
  SELECT categoria, avg(prezzo) AS media
  FROM   prodotti
  GROUP BY categoria
)
WHERE media > 10;
```

::: exercise c8-from

::: tip Sottoquery o JOIN?
Spesso lo stesso risultato si ottiene con un `JOIN`. Le sottoquery sono utili quando ragioni "a strati": prima calcolo questo, poi lo uso lì.
:::
