## La clausola WHERE

`SELECT` sceglie le **colonne**; `WHERE` sceglie le **righe**. Si mette dopo il `FROM`:

```sql
SELECT nome, prezzo
FROM   prodotti
WHERE  prezzo < 20;
```

Il database esamina una riga alla volta: se la condizione è vera la tiene, altrimenti la scarta.

## Confronti

| Operatore | Significato |
|---|---|
| `=` | uguale (in SQL uno solo, non `==`) |
| `<>` oppure `!=` | diverso |
| `<` `>` `<=` `>=` | minore, maggiore, … |

Il **testo** va sempre fra apici singoli; i **numeri** senza:

```sql
WHERE categoria = 'Cucina'
WHERE prezzo >= 10
```

::: warning Apici singoli, non doppi
In SQL le stringhe si scrivono con l'apice singolo: `'Cucina'`. Gli apici doppi `"..."` indicano invece un nome di tabella o colonna.
:::

## Combinare condizioni: AND / OR

- `AND` — vere **entrambe**
- `OR` — vera **almeno una**
- `NOT` — nega la condizione

```sql
WHERE categoria = 'Elettronica' AND prezzo < 30
```

::: exercise c2-and

## Scorciatoie utili

- `IN (a, b, c)` — il valore è uno di quelli elencati
- `BETWEEN x AND y` — compreso fra x e y, estremi inclusi
- `LIKE 'schema'` — confronto di testo con i jolly `%` (una sequenza qualsiasi) e `_` (un carattere singolo)

```sql
WHERE citta IN ('Torino', 'Milano')
WHERE prezzo BETWEEN 10 AND 50
WHERE nome LIKE 'C%'      -- inizia per C
```

::: tip NULL è un caso a parte
Se una casella è vuota il suo valore è `NULL` ("sconosciuto"). I confronti normali con `NULL` non funzionano: si usa `IS NULL` / `IS NOT NULL`. Ne riparliamo con i JOIN.
:::
