## Ordinare: ORDER BY

Va **in fondo** alla query. Indichi la colonna su cui ordinare:

```sql
SELECT nome, prezzo
FROM   prodotti
ORDER BY prezzo;        -- dal più piccolo al più grande
```

- `ASC` — crescente (è il default, di solito si omette)
- `DESC` — decrescente

```sql
ORDER BY prezzo DESC;   -- dal più grande al più piccolo
```

Sul testo l'ordine è alfabetico; sulle date (scritte come `2023-05-01`) è cronologico.

## Più criteri

Separa le colonne con la virgola: la seconda conta solo **a parità** della prima.

```sql
ORDER BY citta, eta DESC;   -- per città; dentro ogni città, dal più vecchio
```

::: exercise c3-order2

## Tenere poche righe: LIMIT

`LIMIT n` tiene solo le prime `n` righe del risultato. Combinato con `ORDER BY` risponde alle domande "i primi / gli ultimi N":

```sql
SELECT nome, prezzo
FROM   prodotti
ORDER BY prezzo DESC
LIMIT 3;                -- i 3 più cari
```

::: exercise c3-limit

::: tip L'ordine delle clausole è fisso
`SELECT` → `FROM` → `WHERE` → `ORDER BY` → `LIMIT`. Scriverle in un altro ordine è un errore di sintassi.
:::
