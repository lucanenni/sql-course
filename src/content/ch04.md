## Colonne calcolate

Nella lista del `SELECT` non sei obbligato a mettere solo nomi di colonna: puoi scrivere **espressioni**.

```sql
SELECT nome, prezzo, prezzo * 1.22
FROM   prodotti;
```

Il database calcola `prezzo * 1.22` per ogni riga e lo mette in una colonna nuova. Funzionano `+ - * /` e le parentesi, e puoi combinare più colonne fra loro (`prezzo * scorta`).

## Dare un nome: AS

Una colonna calcolata ha un nome bruttissimo (tipo `prezzo * 1.22`). Con `AS` gliene dai uno leggibile — che poi puoi riusare in `ORDER BY`.

```sql
SELECT nome, prezzo * 1.22 AS prezzo_ivato
FROM   prodotti
ORDER BY prezzo_ivato DESC;
```

## Funzioni

Una funzione prende uno o più valori e ne restituisce un altro. Alcune utili:

| Funzione | Esempio | Risultato |
|---|---|---|
| `round(x, n)` | `round(3.14159, 2)` | `3.14` |
| `upper(s)` / `lower(s)` | `upper('ciao')` | `'CIAO'` |
| `length(s)` | `length('ciao')` | `4` |
| `abs(x)` | `abs(-7)` | `7` |

```sql
SELECT upper(nome) AS nome_maiuscolo, length(nome) AS lettere
FROM   prodotti;
```

::: exercise c4-round

## Unire testo: `||`

L'operatore `||` **concatena** stringhe. Utile per costruire etichette:

```sql
SELECT nome || ' — ' || categoria AS descrizione
FROM   prodotti;
```

I numeri vengono convertiti in testo automaticamente quando serve.
