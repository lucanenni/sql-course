## DISTINCT — togliere i doppioni

`SELECT DISTINCT` elimina le righe ripetute dal risultato:

```sql
SELECT DISTINCT categoria FROM prodotti;
```

::: exercise c10-distinct

## CASE — un "se… allora…" nelle colonne

`CASE` sceglie un valore in base a delle condizioni, valutate in ordine:

```sql
SELECT nome,
  CASE
    WHEN prezzo < 10 THEN 'economico'
    WHEN prezzo < 40 THEN 'medio'
    ELSE 'caro'
  END AS fascia
FROM prodotti;
```

::: exercise c10-case

Dentro un aggregato, `CASE` diventa un contatore condizionato:

```sql
SELECT sum(CASE WHEN stato = 'annullato' THEN 1 ELSE 0 END) AS annullati
FROM   ordini;
```

::: exercise c10-case-agg

## UNION — impilare due risultati

`UNION` mette in colonna i risultati di due `SELECT` con lo **stesso numero e tipo di colonne**. `UNION` elimina i duplicati, `UNION ALL` li tiene (ed è più veloce).

```sql
SELECT nome FROM clienti WHERE citta = 'Torino'
UNION
SELECT nome FROM clienti WHERE citta = 'Milano';
```

::: exercise c10-union

## Progetto finale

Un'unica query che usa quasi tutto: quattro tabelle in join, un aggregato, `GROUP BY` e `ORDER BY`. Prenditi il tempo che serve — l'indizio spiega i punti delicati.

::: exercise c10-progetto
